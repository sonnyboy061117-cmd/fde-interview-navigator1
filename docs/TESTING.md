## 交互检查

- 四个统计卡片均可筛选材料。
- 切换案件后，筛选恢复为“全部材料”。
- 点击材料后，右侧详情同步更新。
- 手机宽度下案件区可横向滚动，材料详情移到列表下方。
- 所有按钮可通过键盘 Tab 聚焦并使用 Enter/Space 操作。

## 边界检查

- 页面不包含真实个人信息。
- 页面不请求摄像头、定位、文件或联系人权限。
- 页面不包含 API 密钥或登录凭据。
- 页面没有自动外发、写库、核赔或赔付动作。
